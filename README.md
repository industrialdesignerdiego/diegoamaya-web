# diegoamaya-web

Sitio personal de Diego Germán Amaya — https://www.diegoamaya.com.ar

Sitio estático de un solo archivo (`index.html`). No requiere build.

## Publicar en Vercel
Add New → Project → importar este repositorio → Framework: Other → Deploy.
Dominio: Settings → Domains → `www.diegoamaya.com.ar`.

## Editar contenido
Todo el texto está en el objeto `SITE` al comienzo del `<script>` de `index.html`.
Las notas `verify` muestran etiquetas «a verificar» en modo revisión (botón en el pie de página).
